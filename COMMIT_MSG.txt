fix: 空状态整个工作区可交互 - 撑满右侧区域 + 点击任意位置触发上传

问题：空状态界面只有中间内容小块可拖拽/点击，左右两侧与底部空白区域
不响应交互，用户拖拽文件到边缘或点击空白处均无反应。

原因：
1. .main 有 max-width: 1360px + padding: 0 48px 64px，.empty-workspace
   被限制在中间内容区，未覆盖整个右侧工作区
2. 仅主按钮可点击触发上传，空白区域点击无响应

修复：
- App.tsx: 空状态时 main 加 is-empty 类
- layout.css: .main.is-empty 取消 max-width 与底部 padding
- empty-state.css: .empty-workspace 用负 margin(0 -48px) 突破 .main
  左右 padding 撑满 grid 第二列全宽，min-height 调整为 calc(100vh - 64px)
  贴近视口底部；cursor: pointer 暗示可点击
- EmptyWorkspace.tsx: section 加 onClick，点击非按钮区域触发 onUpload，
  通过 closest("button") 排除按钮避免重复弹出文件选择框

验证：npm run build 通过、tsc --noEmit 零错误
